# FilterKit 0.1.14 变更摘要

- 基于 0.1.13 修复后源码增量开发。
- 新增 RFC 5869 HKDF-SHA256 会话密钥派生。
- 新增 256 bit 内存会话密钥生成、到期、轮换和撤销。
- Key ID 与密钥材料分离，避免标识泄露密钥。
- 新增严格协议版本交集协商，拒绝不兼容和异常版本。
- 新增握手转录规范化与 SHA-256 摘要，绑定身份、随机数、版本及只读能力。
- Helper 详情页增加认证握手状态展示。
- 新增 4 个测试套件、37 项登记断言。
- 当前共 31 套件 / 355 项静态登记断言。
- 保持只读预演；不实现真实 IPC、Helper 部署或写操作。
