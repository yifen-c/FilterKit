# FilterKit 0.1.15 变更摘要

- 新增双向 HMAC-SHA256 Key Confirmation。
- 新增严格握手状态机。
- 新增 Peer 身份/构建/凭据摘要绑定模型。
- 新增会话最大寿命、空闲超时和主动失效。
- 根据 0.1.14 设备报告，修复 5 项失败用例（协议错误码、响应测试夹具、plugin.inspect 参数校验、部署证据分类）。
- Nonce 缓存满时改为 fail-closed，不淘汰仍有效条目。
- 增加 Peer 绑定、密钥确认、握手状态和会话过期四类 IPC 审计动作。
- 系统时钟倒退时主动失效会话，并可联动撤销会话密钥。
- Helper 详情页增加认证闭环状态展示。
- 保持只读模式，不创建 Root Daemon、不接真实 IPC、不开放写操作。
